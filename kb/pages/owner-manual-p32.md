# Stick Welding

## ⚠ WARNING

**TO PREVENT SERIOUS INJURY AND DEATH:**
**Do not weld without Grounding Clamp.**
**When the operator is not holding the Electrode Holder, it must be sitting on a nonconductive, nonflammable surface.**

1. Turn the Power Switch to the OFF position, then plug the Welder into a properly grounded, GFCI protected, 120VAC (20 amp rated) outlet or 240V outlet. The circuit must be equipped with delayed action-type circuit breaker or fuses.

2. Set Electrode Holder down on nonconductive, nonflammable surface away from any grounded objects.

3. Turn the Power Switch ON.

4. Press Home Button on Control Panel.

5. Turn Main Control Knob until Stick process appears on LCD display screen.

6. Press Main Control Knob to select STICK process.

**Note:** Press Main Control Knob to go to next screen. Press Back Button to return to the previous screen.

> **[Control Panel with Stick selected — diagram]** Front control panel of the VULCAN OMNIPRO 220 showing the LCD screen displaying "Stick" with the stick-electrode process icon, and a row of process icons along the bottom of the screen with the stick icon highlighted. Buttons and knobs are called out. Data: HOME button at left of screen; BACK button at right of screen; three knobs below the screen labeled (left to right) "Left Knob" (with ⊕/▲ symbol at its left), "Main Control Knob" (center, largest), and "Right Knob" (with ▼ symbol at its right). VULCAN logo with warning/manual icons at upper left; OMNIPRO 220 model badge at upper right.

7. Adjust settings for the STICK process.

   a. Polarity Setting:
      - Plug cables in according to screen.

> **[Stick Polarity Screen — diagram]** LCD screen showing cable connection/polarity instructions for Stick. Data: LEFT side marked "–" (negative) shows a cable plug with a ground/work clamp attached — work clamp goes to the negative (–) socket. RIGHT side marked "+" (positive) shows a cable plug with an electrode holder/stick electrode attached — electrode holder goes to the positive (+) socket (DCEP, straight for 60xx/70xx electrodes). Text at bottom of screen: "No Gas Required". "CONFIRM" with the Main Control Knob icon at the bottom.

   b. Set Electrode type:
      - Turn Main Control Knob to set electrode type.

> **[Electrode Type Screen — diagram]** LCD screen titled "Stick" with the stick process icon. Data: field labeled "Electrode" showing value "60xx". "CONFIRM" with Main Control Knob icon at bottom.

   c. Set Electrode Diameter and Material Thickness:
      - Turn Left Knob to set electrode diameter.
      - Turn Right Knob to set material thickness.

> **[Diameter / Thickness Screen — diagram]** LCD screen titled "Stick". Data: left field labeled "⌀ Diameter" = 3/32"; right field labeled "Thickness" = 16 Ga. Knob indicator icons at far left (⊕/▲ for Left Knob) and far right (▼ for Right Knob) show which knob adjusts which field. "CONFIRM" with Main Control Knob icon at bottom.

   d. Auto Weld Settings:
      - Turn Left Knob to adjust output amperage.
      - Turn Right Knob to ON to energize Electrode Holder.

**WARNING! TO PREVENT SERIOUS INJURY:** Welder is now energized and Open Circuit Voltage is present.

> **[Auto Weld / Run Screen with callouts — diagram]** LCD run screen for Stick welding with labeled callouts pointing to each readout. Data: upper-left large readout "60 A" (set amperage) above "0 A" (actual output amperage); upper-right toggle switch graphic "ON [•] OFF" set to ON, above "0.0 V" (voltage readout). Lower information bar shows: "Stick" with process icon — callout "Process"; "70XX" with electrode icon — callout "Electrode Type"; "⌀ 3/32"" — callout "Electrode Diameter"; "16Ga" with thickness icon — callout "Material Thickness"; bottom-left value "6" with icon — callout "Hot Start"; bottom-right value "0" with icon — callout "Arc Force"; center bottom "SETTINGS" with Main Control Knob icon.
